
# Lab 3

An Android app built in Java for Ubiquitous Computing (COMP H4025).

## What it does
- Starts and stops phone movement monitoring.
- Uses the accelerometer in a separate thread.
- Sends a notification with the time when movement is detected.
- Opens a screen showing the last movement details.

## Tools
Android Studio, Java, XML, Git and GitHub.

## Testing
The project has been built in Android Studio.
No storage so testing on a phone or emulator is still needed to confirm
movement detection and notifications actually work.
